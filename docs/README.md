# General Documentation

Use this folder for project-wide notes that do not fit a single build category.

Suggested additions:
- `assembly-order.md` — the order in which the mechanical, fabric, and electronics assemblies fit together.
- `calibration.md` — tested eye and eyelid servo angles, including safe limits.
- `troubleshooting.md` — symptoms, causes checked, and fixes that worked.
- `photos.md` — labeled links to build photos in `media/photos/`.

## Documentation rule

Separate **tested facts** from **ideas or unverified assumptions**. Include dates and revision numbers when a measurement or wiring choice changes.
