# 3D Printing

Store printable parts and their source files in this folder.

## Files to add

- `.stl` — ready-to-slice mesh files
- `.3mf` — slicer project with orientation/settings when practical
- `.step` / native CAD files — editable source geometry
- `.png` — screenshots showing orientation or assembly

## Notes to document

1. Part name and purpose.
2. File version and required quantity.
3. Printer, filament/material, nozzle, layer height, infill, supports, and orientation.
4. Any post-processing, inserts, screws, or glue.
5. Fit problems and the changes made to fix them.

Do not label a part "final" until it has been test-fitted in the actual assembly.
