# Media

Add photos and diagrams here, then link them from the relevant documentation.

- `photos/` — progress photos, fit checks, wiring close-ups, finished build.
- `diagrams/` — pin map, wiring diagram, assembly diagrams, fabric pattern previews.

Use descriptive filenames such as `servo-mount-rev2.jpg` or `power-distribution-v1.png`. Avoid uploading private information or photos that reveal personal details you do not want public.
